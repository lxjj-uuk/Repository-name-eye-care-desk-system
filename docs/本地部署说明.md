# 本地部署说明

本模式在 Windows 电脑上运行 FastAPI、SQLite 和本地中文模型，不依赖
华为 IoTDA、组员电脑或第三方云平台。

## 启动

双击项目根目录的：

```text
start-local.cmd
```

脚本会：

- 启动 `backend\.venv` 中的 FastAPI。
- 使用 `backend\eye_care.db` 保存设备、遥测、命令和报告。
- 检查 `http://127.0.0.1:8080/health`。
- 自动检测电脑局域网 IP。
- 更新 `gateway\esp32\include\cloud_config.local`。

本地地址：

```text
API 文档：http://127.0.0.1:8080/docs
模拟器：  http://10.0.2.2:8080
局域网：  http://<电脑局域网IP>:8080
```

## AI 分析

推荐使用随项目配置的 `Qwen2.5 1.5B Instruct` 本地模型。首次部署运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\download-ai-model.ps1
backend\.venv\Scripts\python -m pip install -r backend\requirements-ai.txt
```

模型路径为：

```text
models\qwen2.5-1.5b-instruct-q4_k_m.gguf
```

模型约 1.1 GB，不会提交到 Git。启动后可访问
`http://127.0.0.1:8080/health`，确认 `ai.local_available` 为 `true`。
App 点击“AI 深度分析”时会显示分析进度；完成后，报告上方会标注
“本地大模型”、模型名称和生成时间。

本地模型不可用或分析失败时，后端自动回退到 `rule+risk-model`，不会
让接口失效。也支持 OpenAI-compatible 在线模型，在 `backend\.env` 设置：

```text
LLM_API_URL=https://your-llm-endpoint/v1/chat/completions
LLM_API_KEY=your-key
LLM_MODEL=your-model
```

系统优先使用本机模型；本机推理失败后再尝试在线接口。

## ESP32

本地地址会写入被 Git 忽略的 `cloud_config.local`。电脑网络变化后，
需要重新运行 `start-local.cmd`，再重新编译和烧录 ESP32：

```powershell
cd gateway\esp32
..\..\backend\.venv\Scripts\pio.exe run
..\..\backend\.venv\Scripts\pio.exe run --target upload --upload-port COM6
```

ESP32、手机和电脑必须在同一个局域网。Windows 防火墙需允许本机 TCP
`8080` 端口的入站访问。

### Windows 移动热点联调

如果现场路由器启用了客户端隔离，可在 Windows 设置中手动开启“移动热点”：

```text
网络名称：EyeCare-Local
网络密码：EyeCare2026
频段：2.4 GHz
```

热点开启后再次运行 `start-local.cmd`。脚本会识别热点地址
`192.168.137.1` 并更新 ESP32 配置。随后在 ESP32 中通过 BLE 配置热点，
重新编译并烧录固件。

## 停止

双击项目根目录的：

```text
stop-local.cmd
```
