# 本地部署说明

本模式在 Windows 电脑上运行 FastAPI、SQLite 和规则风险分析，不依赖
华为 IoTDA、组员电脑或第三方云平台。

## 启动

双击项目根目录的：

```text
start-local.cmd
```

脚本会：

- 启动 `backend\.venv` 中的 FastAPI。
- 使用 `backend\eye_care.db` 保存设备、遥测、命令和报告。
- 检查 `http://127.0.0.1:8080/health`。
- 自动检测电脑局域网 IP。
- 更新 `gateway\esp32\include\cloud_config.local`。

本地地址：

```text
API 文档：http://127.0.0.1:8080/docs
模拟器：  http://10.0.2.2:8080
局域网：  http://<电脑局域网IP>:8080
```

## AI 分析

未配置大模型时，后端使用 `rule+risk-model` 本地分析，生成风险等级、
原因分析和改善建议。若要接入在线大模型，在 `backend\.env` 设置：

```text
LLM_API_URL=
LLM_API_KEY=
LLM_MODEL=
```

## ESP32

本地地址会写入被 Git 忽略的 `cloud_config.local`。电脑网络变化后，
需要重新运行 `start-local.cmd`，再重新编译和烧录 ESP32：

```powershell
cd gateway\esp32
..\..\backend\.venv\Scripts\pio.exe run
..\..\backend\.venv\Scripts\pio.exe run --target upload --upload-port COM6
```

ESP32、手机和电脑必须在同一个局域网。Windows 防火墙需允许本机 TCP
`8080` 端口的入站访问。

## 停止

双击项目根目录的：

```text
stop-local.cmd
```
