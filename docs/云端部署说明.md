# Eye Care 云端部署

当前交付阶段使用自有 FastAPI 服务作为云端，不再依赖华为云 IoTDA。

```text
Hi3861 -> ESP32-C3 -> HTTPS/JSON -> FastAPI -> App
```

## Render 部署

1. 将 GitHub 仓库导入 Render。
2. 选择 Blueprint，读取仓库根目录的 `render.yaml`。
3. 在环境变量页面填写：
   - `API_TOKEN`：设备上传接口令牌
   - `DEMO_PASSWORD`：App 演示登录密码
   - `LLM_API_URL`、`LLM_API_KEY`、`LLM_MODEL`：可选，未配置时使用规则分析
4. 部署完成后访问：

```text
https://<service-name>.onrender.com/health
https://<service-name>.onrender.com/docs
```

## App 配置

在 App 设置页把后端地址改为 Render 的 HTTPS 地址，例如：

```text
https://eye-care-cloud.onrender.com
```

## 设备上传

ESP32-C3 通过 HTTPS 调用：

```text
POST /ingest/telemetry
Authorization: Bearer <API_TOKEN>
Content-Type: application/json
```

示例数据：

```json
{
  "lux": 320,
  "temperature": 23.1,
  "humidity": 38.5,
  "light_state": "normal",
  "occupied": true,
  "sit_cont_min": 25,
  "sit_total_min": 65,
  "last_motion_min": 1,
  "risk": 0.28,
  "risk_level": "low"
}
```

SQLite 适用于当前试运行。Render 免费实例重建后数据可能重置，正式上线时再切换托管 PostgreSQL/MySQL。
